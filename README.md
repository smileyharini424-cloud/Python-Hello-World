# Python Hello World

## Explanation

This is the first program in the Python Basics series. It demonstrates how to display a message on the screen using Python's built-in `print()` function.

## Problem Statement

Write a Python program to display the message "Hello, World!" on the screen.

## Features

* Simple Python program
* Uses the `print()` function
* Beginner-friendly
* No external libraries required

## How It Works

The `print()` function is used to display text or values on the screen.

In this program, the message `"Hello, World!"` is passed to the `print()` function.

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Call the `print()` function.
3. Display "Hello, World!".
4. End the program.

## Sample Input

No input is required.

## Sample Output

```text
Hello, World!
```
